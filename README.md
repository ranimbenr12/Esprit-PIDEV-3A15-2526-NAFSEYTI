# NAFSEYTI-
🧠 NAFSEYTI – Application Web Java de Suivi Psychologique Universitaire

NAFSEYTI est une application web développée en Java (JEE) visant à améliorer le bien-être psychologique des étudiants au sein de l’université.
Elle permet de digitaliser la gestion des rendez-vous, du suivi psychologique et de la communication entre étudiants, psychologues et administrateurs.

La plateforme offre une solution moderne, sécurisée et centralisée remplaçant les méthodes traditionnelles (papier, appels, gestion manuelle).

👉 Ce projet a été conçu et réalisé par l’équipe Nexus Group.

🎯 Objectifs

Faciliter la prise de rendez-vous en ligne

Assurer un suivi personnalisé des étudiants

Centraliser les informations psychologiques

Réduire la charge administrative

Garantir la confidentialité et la sécurité des données

👥 Acteurs
👨‍🎓 Étudiant

Réserver / annuler / modifier un rendez-vous

Consulter son historique

Suivre ses objectifs personnels

🧑‍⚕️ Psychologue

Gérer son planning

Consulter les rendez-vous

Ajouter des notes de suivi

👨‍💼 Administrateur

Gérer les utilisateurs

Superviser la plateforme

🛠️ Technologies utilisées

Java JEE (Servlets, JSP)

Maven

JDBC

MySQL

HTML / CSS / Bootstrap

Architecture MVC

Git & GitHub

IntelliJ IDEA

🏗️ Architecture

L’application adopte l’architecture MVC (Model–View–Controller) :

Model → gestion des données

View → interfaces JSP

Controller → Servlets

Cela permet un code structuré, maintenable et évolutif.
